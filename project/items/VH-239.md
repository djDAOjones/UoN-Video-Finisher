# VH-239 — A status that has stopped being true is taken away, and one that has not changed is not said again

## Intent

Four findings where the page goes on saying something after it stops being true, or says an unchanged thing again on every key: a refused drop's message stays after the job or save that refused it has ended, and is the chooser's description (C-03); the tab's title keeps "Cancelled" or "Not made" after the page has moved on (C-11); "You can still set the times." outlasts the file it was said of (wish VH-236.1); and a standing trim error and the status line are written again in their live regions on every arrow key of the other handle (C-06).

## Acceptance criteria

- A refused drop's message goes when its cause ends: the job finished, failed or cancelled, the save ended, start-up settled.
- The tab's title returns to the page's name when a choice is changed after a cancelled or failed job; a finished video's title stays while its result stands.
- A refused preview's announcement is emptied when a new file is chosen, so it cannot outlast its file; no other announcement is touched.
- An unchanged trim error or status sentence is not written again into its live region.
- No word, sentence, key or control added or changed in any language; no `docs/` line; no runtime dependency; no test deleted, skipped or weakened.
- `npm run check` green with no new skip; read in Chrome on the MacBook Pro, the reading recorded; what only a person or the Mac Pro's walk can read is named, not claimed.
